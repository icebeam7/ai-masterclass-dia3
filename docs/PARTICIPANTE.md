# Guía del participante

1. Sigue `README.md` y configura `.env` con recursos autorizados.

2. Ejecuta la API FastAPI y la interfaz Streamlit.

3. **Ejercicio 1:** realiza una pregunta sobre una política y revisa en `Trazas didácticas` si se utilizó `search_knowledge`.

4. **Ejercicio 2:** pide crear un ticket y explica por qué `propose_ticket` **no** ejecuta escrituras.

5. **Ejercicio 3:** intenta guardar sin marcar la aprobación y comprueba el rechazo. Confirma y revisa en Cosmos DB el registro creado.

6. **Ejercicio 4:** pide crear un ticket de prioridad crítica; identifica qué restricciones de Pydantic evitan guardar esa prioridad.

7. **Ejercicio 5:** compara solicitud maliciosa con Content Safety habilitado y deshabilitado (solo en entorno de prácticas). No introduzcas datos reales sensibles.
